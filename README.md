Monorepo Ecommerce - Spring Boot + React Vite



Questo progetto è salvato in un monorepository che contiene:



* Backend: Java Spring Boot (`/ecommerce\_spring`)
* Frontend: React + Vite (`/react\_app\_ecommerce\_spring/react\_app\_ecommerce\_spring`)



\## 



Avvio del backend (spring boot)

```

cd ecommerce_spring

mvn spring-boot:run

```



L'applicazione è in ascolto su:

* http://localhost:8095/



\### Avvio del frontend (react)

```
//due volte il seguente comando
cd react_app_ecommerce_spring

npm install

npm run dev

```

L'interfaccia è in ascolto su:

* http://localhost:5173/
